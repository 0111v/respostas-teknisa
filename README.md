# Teste Técnico - Desenvolvedor

Este repositório contém as soluções para o teste técnico proposto pela empresa. 

Alguns arquivos podem ser testados diretamente no navegador (HTML/JS/CSS), outros exigem Node.js para execução.

##  Observações

- Todos os exercícios foram resolvidos sem o uso de bibliotecas externas, respeitando os requisitos de cada questão.
- Comentários foram incluídos em alguns arquivos para facilitar o entendimento das lógicas implementadas.
